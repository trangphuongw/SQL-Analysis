## Introduction
The sales data set includes 5 tables, which are 1 fact table about sales orders and 4 dimension tables about product, category, territory and customer data
  
🔎 I analyzed:
* Top products
* Territory revenue share contribution
* Return buyer rate
* Discover buyer customer demographics

The goal is simple: to find out which factors had the most positive impact on business revenue to leverage in the future

## Tool I used
- SQL: allowing me to query the data, uncover patterns, and answer key questions about sales, products and demographics
- BigQuery: the database management system I used to store, organize, and work with the fact&dim data efficiently
- GitHub: Used for sharing my SQL scripts, analysis, and project results
